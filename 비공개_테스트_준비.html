구글 공식 문서 (answer/14151465 — 오늘 한국어 · 영어판 확인)
  • 개인 계정(2023-11-13 뒤 만든 계정)은 테스터 12명 이상이 14일 연속 참여해야 프로덕션 신청 가능. 날짜는 테스터 참여로 세고 앱 버전과는 상관없음. 중간에 나갔다 다시 들어온 테스터는 다시 14일 연속이어야 함.
  • "프로덕션 전에 비공개 테스트에서 업데이트하면 낮은 평점을 줄인다", "버그를 고치는 동안 테스트를 계속하라" — 테스트 중 업데이트를 권함.
  • 프로덕션 신청서 질문: 테스터 모집이 쉬웠나 · 테스터가 모든 기능을 썼나 · 의견 요약과 모은 방법 · 테스트에서 배운 것으로 바꾼 것 · 출시 준비가 됐다고 판단한 방법 → 테스트 중 고친 게 오히려 답이 됨.
  • 구글이 보는 것: 테스터 참여가 부족하면 테스트를 더 하라고 함 · 튕김 · 고장 난 기능 · 빈 화면이 없을 것 · 검토는 보통 7일 안.
  • 문서에 없는 것: 업데이트를 올리면 14일이 다시 시작되는지 → 문서에 없음(날짜를 테스터 참여로 세니 다시 시작되지 않는 것으로 읽힘). 카치건도 테스트 기간(10-24 ~)에 광고 · 결제 빌드를 올렸고 그대로 신청했습니다.
지금 게임에서 찾은 것 — 테스트 빌드 전에 꼭 고칠 것
  1. 광고 [초안]이 폰에서도 "바로 성공" (Ads.Draft = true → 광고 없이 보상 2배 · 광고 상자). 이대로 나가면 테스터가 광고 보상을 공짜로 받아서 밸런스 의견이 틀어지고, 프로덕션에 나가면 광고 수익도 없습니다 → 결정 ④.
