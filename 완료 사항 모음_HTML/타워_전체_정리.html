02 핵심 전투 공식 & 인게임 업그레이드 규칙

최종 피해 = ATK × (Rate / 100) × (1 + 일반 합) × (1 + 후반 합) × 치명 × 약점/저항 × 거리 × 멀티샷 페널티 × (1 + 취약) × (1 - 적 장갑)
• ATK = 기지 공격력 × (1 + 기지 공격력% 회로) + 장비 공격력 × (1 + 장비 공격력% 회로)
• 일반 합 = 로비 터렛 레벨 피해 보너스 + 인게임 카드 dmg% + 조건/속성/전용 회로 + 마비/둔화 특공
• 후반 합 = 해당 터렛 스킨 보유 시 +10% (별도 곱연산 브래킷)
• 쿨다운 = 기본 Cooldown × 터렛 레벨 Cd_Mul / (1 + 공속% / 100) · 틱 간격 = 기본 Tick / (1 + tick% / 100)

인게임 레벨업 · 별 · 돌파 규칙

  • 배치 슬롯: 대장 카피(슬롯 0 고정) + 터렛 4칸 (Turret_Slots = 4).
  • 레벨 상한: 일반/엘리트/엘리트 군단 Lv.20 · 무한 모드 Lv.30. 레벨업마다 카드 3장 제시(광고 새로고침 판당 1회).
  • 별 & 돌파(Tier 1 → 2 → 3): 새 터렛 배치 시 별 1개 시작(전용 별 회로로 최대 +2). 카드 선택마다 별 +1 → 별 4개 도달 시 일반·연계 카드가 잠기고 돌파 카드(A/B)만 등장(가중치 ×4, 보스 추가 카드는 돌파/연계/콤보 ×3).
  • 돌파 효과: 돌파 선택 시 단계 +1(최대 3단계), 별 0 초기화, 전장 타워 크기 1.0 → 1.1 → 1.2배 증가 + 붉은색 각성 연출.
  • 멀티샷 페널티: shots · count · bounce 키 카드는 1장당 발당 피해 ×0.85 (-15%) 곱연산. 반면 shots_free · count_free · bounce_free 카드는 피해 감소 없음.

속성 · 거리 · 치명타 · 곁가지 공격 규칙

  • 약점 / 저항: 스테이지 약점 또는 적 약점 일치 시 ×2.0배(중복 적용 없음), 적 저항 속성 시 ×0.6배.
  • 치명타: 기본 확률 5%, 기본 배율 1.5배 (+치명 피해 회로 합산). 처형 회로 장착 시 치명타에 적 최대 체력% 추가 피해(상한 원래 피해 ×4).
  • 거리 보정: 방어선 근처 적(VY < -1.6) ×1.1배, 먼 적(VY > 5.0) ×0.9배.
  • 곁가지 공격(procs=false): 폭발·연쇄 번개·분열탄·산탄·불바다·굴절 빔 등 파생 타격은 무한 연쇄 방지를 위해 적중/처치 부가 효과를 다시 발동하지 않습니다.
  • 연사 회로(부츠): 대장 카피를 제외한 모든 터렛이 발사 시 최대 50% 확률(회로 수치)로 1회 추가 발사합니다.

상태이상 및 군중 제어(CC) 판정

  • 둔화 (Slow): 이동 속도 감소, 기본 최대 50%(끈끈이 드론 정지장 보유 시 최대 90%).
  • 마비 (Paralyze): 기본 1초간 이동 및 기지 공격 정지. 보스는 면역.
  • 화상 (Burn): 기본 3초간 초당 40% ATK × (1 + 일반 보너스) 피해(0.5초마다 틱). 더 강한 화상으로 갱신.
  • 취약 (Vulnerable): 기본 4초간 적이 받는 모든 피해 증가(가장 높은 수치 유지).
  • 밀어내기 / 끌어당김: 보스는 완전 면역. 밀어내기는 중간 보스(엘리트)에게 30%만 적용.
  • 피해 공식, 약점/저항 배율, 치명타, 상태이상 수치 변경 의견
  • 인게임 슬롯 수, 레벨 상한, 별/돌파 규칙, 멀티샷 페널티 변경 의견
