# 스토리 개편안 적용 가이드

이 폴더(`스토리_개편안/`)의 파일들은 **게임에 아직 반영되지 않은 준비용 데이터**입니다.
내용을 검토하신 뒤 원하실 때 아래 순서로 바로 적용할 수 있습니다.

## 포함된 파일
| 파일 | 용도 | 게임 반영 위치 |
| :--- | :--- | :--- |
| `Story_New.xlsx` | 엑셀 원본 (`Story` 581줄 / `Lobby_Talk` 36줄 / `String_Add` 4줄) | `Earth_Defence/Table/Story.xlsx` (`Story`, `Lobby_Talk` 시트) |
| `Story_New.csv` | 스테이지/프롤로그/에필로그 대사 CSV (총 102편 · 581줄, UTF-8 BOM) | `Earth_Defence/Assets/Resources/Tables/Story.csv` |
| `Lobby_Talk_New.csv` | 로비 대장 카피 말풍선 36개 CSV (UTF-8 BOM) | `Earth_Defence/Assets/Resources/Tables/Lobby_Talk.csv` |
| `String_Add.csv` | 신규 보스 4종 이름표 (`who_frost_emperor` 등) | `Earth_Defence/Table/String.xlsx` & `Assets/Resources/Tables/String.csv`에 4줄 추가 |
| `스토리_개편안_검토.html` | 전체 102편 + 로비 말풍선 검토 문서 | 브라우저로 열어 검토 (체크 · 의견 저장 가능) |
| `generate_story_data.py` | 위 파일들을 한 번에 재생성 + `Jua-Regular.ttf` 글꼴 누락 검사 | 대사 수정 후 `python -X utf8 generate_story_data.py` 실행 |

## 추후 게임 반영 절차
1. **대사 표 반영**
   - `Story_New.csv` → `Earth_Defence/Assets/Resources/Tables/Story.csv`로 복사
   - `Lobby_Talk_New.csv` → `Earth_Defence/Assets/Resources/Tables/Lobby_Talk.csv`로 복사
   - 엑셀 원본도 동기화하려면 `Story_New.xlsx`의 `Story`, `Lobby_Talk` 시트를 `Earth_Defence/Table/Story.xlsx`로 교체
2. **신규 보스 화자 이름표 추가 (4줄)**
   - `String_Add.csv`의 4줄(`who_frost_emperor`, `who_mecha_crab`, `who_ring_wyrm`, `who_jelly_king`)을 `String.xlsx` / `String.csv`에 추가
   - `StoryView.Face()` (`Assets/Scripts/UI/Story.cs`)는 이미 `Tables.Enemies`에서 초상화를 자동 로드하므로 코드 수정 없이 보스 얼굴이 바로 표시됩니다.
3. **(선택) St.100 클리어 에필로그 연결**
   - `Story_New.csv` 안에 `Id = epilogue`(13줄)가 이미 포함되어 있습니다.
   - 스테이지 100 첫 클리어 시 결과 창 앞 또는 로비 복귀 시점에 `if (stage == 100 && StoryView.Want("epilogue")) StoryView.Play("epilogue", 0, ...)` 한 줄만 연결하면 엔딩 대화가 재생됩니다.
